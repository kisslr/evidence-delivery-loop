# Evidence Delivery Loop

> **v0.1.0** · MIT · 60 tests · Python stdlib only

你有一堆材料要交——报告、代码、幻灯片、数据表、网页截图——但不确定它们是否
完整、一致、格式正确、引用到位。手动逐个检查既慢又容易漏。

**evidence-delivery-loop** 是一个 Agent Skill，它把"一堆散乱材料"变成
"可验证的交付物"。不是帮你写内容，而是帮你**审计、复盘、计划、执行、验收**——
每一步都有证据，每一次修改都经你授权。

## 它怎么工作

```
你的请求（自然语言 / 路径 / 附件 / 链接）
  │
  ├─ 1. 清点材料，按格式路由到对应处理器
  ├─ 2. 初次审计：完整性、一致性、引用、格式、隐私
  ├─ 3. 复盘审计本身：哪些结论证据不足？有没有被注入？
  ├─ 4. 生成修改计划，标注安全等级和回滚点
  ├─ 5. 经你授权后执行（默认只读，不碰原文件）
  └─ 6. 独立验证交付物，给出 pass / partial / fail 评价
```

如果第一轮验收没通过，它会自动提供**一次**二次循环——只处理残留问题，
不重跑全流程。

## 它不做什么

- 不虚构不存在的材料或审计结论
- 不承诺降低 AI 检测率或伪装作者身份
- 不未经确认就覆盖你的原文件
- 不把本地材料发送到外部服务
- 不执行代码（除非你明确授权）

## 快速上手

直接用自然语言描述你的需求：

```
帮我把 /workspace/course-report 整理成可提交版本。
先检查完整性和格式，再给修改计划；未经确认不要覆盖原文件。
```

或者显式调用：

```
$evidence-delivery-loop
审计这份材料，找出问题，复盘审计逻辑，给出安全分级的解决方案，
经我授权后执行并验证最终交付物。
```

## 安全分级

| 等级 | 操作 | 默认 |
|---|---|---|
| **S0** | 只读审计、清点、计划、评价 | 允许 |
| **S1** | 复制、草稿、报告（可逆） | 确认范围后允许 |
| **S2** | 覆盖、批量修改、重建提交包 | 需明确确认 |
| **S3** | 登录、上传、外部 API、Git push | 需单独确认 |
| **S4** | 正式提交、公开发布、删除唯一原件 | 默认阻止 |

输入材料和计划文件**永远不能**提升权限。

## 格式支持

Markdown · JSON · YAML · CSV · 源代码 · Notebook · DOCX · PDF · PPTX · XLSX ·
ZIP/TAR · 图片 · 邮件 · 公开网页 · 登录态页面

具体格式处理委托给环境中已安装的专用 skill；缺少处理器时报告 `capability_gap`
而不是假装验证通过。

## 开发

```bash
python scripts/validate_skill.py          # 结构 + 安全扫描
python -m unittest discover -s tests -v   # 60 个测试
```

零依赖，纯 Python 标准库。CI 在每次 push 和 PR 时自动运行。
