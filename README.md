# Evidence Delivery Loop

evidence-delivery-loop 是一个面向 Codex 和兼容 Agent Skills 的流程型 skill，
用于把“材料输入”推进到“可验证交付”。它适合课程作业、研究材料、代码项目、
多格式报告、网页资料和提交包等需要审计、复盘、计划、执行、验收的任务。

## 核心流程

```text
自然语言 / 路径 / 附件 / 文本 / 公开链接
  -> 材料清点与格式路由
  -> 初次审计
  -> 审计复盘与根因分析
  -> 解决方案和执行计划
  -> 计划复盘与安全审核
  -> 授权后执行
  -> 格式、运行和证据验证
  -> 相对评价与第二轮入口
```

它不会把不存在的材料当成已审计事实，也不会把表达优化变成伪装文本或规避
AI 检测。它负责流程、权限和证据边界；DOCX、PDF、PPTX、表格、Notebook、
浏览器等具体操作交给环境中已经安装的专用 skill。

## 低门槛调用

可以直接用自然语言、文件路径、附件、粘贴文本或公开 URL，例如：

```text
帮我把这个目录整理成可提交版本：/workspace/course-report
先检查完整性和格式，再给出详细修改计划；未经我确认不要覆盖原文件。
```

也可以显式调用：

```text
$evidence-delivery-loop
审计这份材料，找出问题，复盘审计逻辑，给出安全分级的解决方案，
经我授权后执行并验证最终交付物。
```

## 安全边界

默认从 S0 只读审计开始。复制和草稿属于 S1；覆盖、批量修改和重建提交包属于
S2；登录、上传、受限下载、外部 API 和 Git push 属于 S3；正式提交、公开发布、
删除唯一原件和生产变更属于 S4。计划文件和输入材料不能提升权限。

## 开发与验证
